# Role Onboarding Checklist

This checklist helps new team members onboard to their role at OctoAcme. Customize based on the specific role and project context.

## General Onboarding (All Roles)

- [ ] Complete company orientation and HR paperwork
- [ ] Set up development environment and access credentials
- [ ] Review [Project Management Overview](./octoacme-project-management-overview.md)
- [ ] Read [Roles & Personas](./octoacme-roles-and-personas.md) to understand team structure
- [ ] Join relevant communication channels (Slack, Teams, email lists)
- [ ] Schedule 1:1 introductions with key team members
- [ ] Review project board and current sprint/milestone status
- [ ] Understand escalation paths and reporting structure

## Role-Specific Onboarding

### Developer
- [ ] Clone repositories and verify build environment
- [ ] Review coding standards and contribution guidelines
- [ ] Complete code review training and shadow experienced developers
- [ ] Review [Execution & Tracking](./octoacme-execution-and-tracking.md) documentation
- [ ] Understand CI/CD pipeline and testing requirements
- [ ] Pick up first starter issue and create pull request

### Product Manager
- [ ] Review product roadmap and backlog priorities
- [ ] Meet with stakeholders to understand business objectives
- [ ] Review [Project Initiation Guide](./octoacme-project-initiation.md)
- [ ] Understand success metrics and measurement approach
- [ ] Shadow customer research sessions or review recent findings
- [ ] Attend sprint planning and demo sessions

### Project Manager
- [ ] Review active projects, timelines, and dependencies
- [ ] Access project management tools (boards, schedules, risk registers)
- [ ] Review [Project Planning](./octoacme-project-planning.md) documentation
- [ ] Review [Risk Management & Communication](./octoacme-risks-and-communication.md)
- [ ] Schedule weekly syncs with PM and engineering leads
- [ ] Understand stakeholder communication cadence and requirements

### Release Manager
- [ ] Review [Release & Deployment Guide](./octoacme-release-and-deployment.md)
- [ ] Access release management tools and CI/CD systems
- [ ] Review [Release Manager Checklist](./release-manager-checklist.md)
- [ ] Understand deployment environments and procedures
- [ ] Review rollback and incident response procedures
- [ ] Shadow next scheduled release deployment

### Risk & Compliance Lead
- [ ] Review risk register and current risk status
- [ ] Understand compliance requirements and audit schedule
- [ ] Review [Risk Escalation Path Template](./risk-escalation-path-template.md)
- [ ] Access security scanning tools and results
- [ ] Meet with leadership to understand risk tolerance
- [ ] Review previous incident reports and lessons learned

### Technical Architect
- [ ] Review system architecture documentation and diagrams
- [ ] Understand current technical stack and design patterns
- [ ] Review technical debt and architectural improvement backlog
- [ ] Meet with development teams to understand current challenges
- [ ] Review technical decision-making processes
- [ ] Attend architecture review sessions

### External Stakeholder
- [ ] Review project charter and business objectives
- [ ] Understand deliverables, milestones, and acceptance criteria
- [ ] Schedule regular status update meetings
- [ ] Establish communication preferences and escalation contacts
- [ ] Review demo schedule and feedback processes
- [ ] Clarify decision-making authority and approval processes

### Change Manager
- [ ] Review change management process and approval workflows
- [ ] Access change logs and historical change records
- [ ] Understand impact assessment criteria and processes
- [ ] Review communication templates for change notifications
- [ ] Meet with Project Managers to understand current changes
- [ ] Establish change review meeting cadence

## First Week Activities

- [ ] Complete role-specific onboarding checklist
- [ ] Participate in daily standup (if applicable)
- [ ] Shadow at least 2 key meetings relevant to your role
- [ ] Complete first meaningful contribution or deliverable
- [ ] Schedule end-of-week check-in with manager

## First Month Milestones

- [ ] Demonstrate understanding of core responsibilities
- [ ] Establish working relationships with cross-functional partners
- [ ] Complete initial contributions with minimal guidance
- [ ] Provide feedback on onboarding process for continuous improvement
- [ ] Set 90-day goals with manager
